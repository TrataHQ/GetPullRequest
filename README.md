# GPR docs

Mintlify documentation for [GetPullRequest](https://getpullrequest.com).

Content is grounded in `apps/gpr` in the monorepo. See `AGENTS.md` for writing rules.

## Local preview

Requires an LTS Node version (Mintlify CLI does not support Node 25+).

```bash
npm i -g mint
mint dev
```

Open `http://localhost:3000`.

## Structure

Configured in `docs.json`:

- Get started → 5-minute setup
- How GPR works
- Guides
- Integrations (GitHub, Jira, Slack, coding agents)
- Reference
- Security
