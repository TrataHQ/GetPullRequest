---

Slack is an optional chat enrichment. Connect it to turn supported mentions / channel flows into board tasks.

## Connect

1. Open **Settings → Connections**.
2. Connect **Slack** and finish OAuth.
3. Select the channels the app offers for linking.

## What you get

- Tasks sourced from Slack (`source_provider: slack`)
- A path from conversation → board without copying text by hand

## What you still need

Same as other sources: online workspace, ready agent, and a code host if you want GitHub PRs.

## Support vs tasking

GPR also uses Slack in some support/ops tooling. The product integration you configure in **Settings → Connections** is the user-facing OAuth path for workspace tasking.
