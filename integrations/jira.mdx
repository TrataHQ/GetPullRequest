title: "Jira"
description: "Connect Jira to sync issues onto the GPR board."
---

Jira is an optional issue-tracker enrichment. Connect it when you want Jira issues on the GPR board alongside in-app and GitHub tasks.

## Connect

1. Open **Settings → Connections**.
2. Connect **Jira** and finish OAuth.
3. Link the Jira project / site the app prompts for.

## What you get

- Issue sync onto the kanban board (`source_provider: jira`)
- Task metadata from the Jira issue
- Status mapping back through the sync worker where configured

## What you still need

- A paired machine with `gpr` online
- A ready coding agent on that machine
- GitHub (or local git remotes) if you want hosted pull requests

Jira does not run the agent. It supplies work items into the same task pipeline.
